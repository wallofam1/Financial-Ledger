Crypto wallets

Needed to read Base and Solana wallet balances. Get a free key at alchemy.com. Alchemy keys often work across chains automatically — if a wallet fails to refresh, create a separate app for that specific network in your Alchemy dashboard and use its key instead. Ledger only ever reads a public wallet address; it never asks for a private key or seed phrase.
